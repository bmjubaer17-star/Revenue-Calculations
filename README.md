# Profit Margin Calculator

A simple, responsive web app that calculates gross profit, gross margin, operating profit, net profit, net margin and markup.

## Run locally
Open `index.html` in a browser, or use the **Live Server** extension in VS Code.

## Formulas
- Gross margin = (Revenue − COGS) ÷ Revenue × 100
- Markup = (Revenue − COGS) ÷ COGS × 100
- Net profit = Operating profit − tax (tax applies only to positive profit)

## Deploy on GitHub Pages
Push to GitHub, then go to **Settings → Pages**, choose the `main` branch and `/ (root)`.
